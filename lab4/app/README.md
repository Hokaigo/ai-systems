# AI English Quiz Generator

Вебзастосунок для автоматичної генерації тестів англійською мовою на основі введеного тексту. Використовує локальну малу мовну модель через OpenAI-сумісний API.

## Вимоги
1. **Node.js** (v18+) для запуску React-середовища. Завантажте та встановіть з [офіційного сайту Node.js](https://nodejs.org/).
2. **Ollama** для підняття локального сервера нейромережі. Завантажте та встановіть з [офіційного сайту Ollama](https://ollama.com/).

## Завантаження моделі
Застосунок оптимізовано для роботи з моделлю `qwen2.5:1.5b`. Щоб завантажити її, відкрийте термінал і виконайте:

```bash
ollama pull qwen2.5:1.5b
```

## Як запустити

### Крок 1. Запуск сервера Ollama з дозволом CORS
Оскільки React-застосунок робить запити напряму до локального API, необхідно дозволити крос-доменні запити (CORS).
Відкрийте термінал і запустіть Ollama з відповідною змінною середовища:
* **Windows (PowerShell):** `$env:OLLAMA_ORIGINS="*"; ollama serve`
* **Windows (CMD):** `set OLLAMA_ORIGINS="*" && ollama serve`
* **Mac/Linux:** `OLLAMA_ORIGINS="*" ollama serve`

### Крок 2. Запуск вебзастосунку
Відкрийте інший термінал у папці з проєктом та виконайте:

```bash
npm install
npm run dev
```

Застосунок буде доступний у браузері за адресою `http://localhost:5173`.
